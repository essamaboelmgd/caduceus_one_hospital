# Caduceus One Hospital – Data Analytics Project

## 📋 نظرة عامة
يهدف هذا المشروع إلى تحليل بيانات مستشفى Caduceus One باستخدام **Power BI** لإنشاء لوحات مؤشرات (Dashboards) شاملة تدعم اتخاذ القرار.  
يتضمن العمل جمع البيانات من أكثر من 17 جدولًا من نظام إدارة المستشفى (HMS)، تنظيفها، ثم تصميم نموذج بيانات وتحليلات KPI.

## 🛠️ توزيع المهام

### Phase 1 – Project Setup & Data Gathering
- **Belal Emad (Project Manager & Data Coordinator)**  
  - تحديد نطاق المشروع والأهداف  
  - إعداد قائمة مصادر البيانات وتنسيق استخراجها  
  - إعداد خطة المشروع والجدول الزمني  

- **Essam Abo Elmgd (Technical Lead)**  
  - تقييم جودة البيانات واكتمالها  
  - إنشاء هيكل مشروع Power BI ونموذج البيانات المبدئي  

- **Bakr Ahmed (Data Analyst)**  
  - جمع متطلبات الـKPIs والتصورات  
  - توثيق الأسئلة التجارية لكل قسم  
  - إنشاء نموذج مبدئي للوحة التحكم  

- **Mostafa Mohamed (Quality Assurance)**  
  - التحقق من صلاحيات الوصول للبيانات  
  - إعداد قائمة تحقق لجودة البيانات  
  - وضع سيناريوهات الاختبار

### Phase 2 – Data Cleaning & Preparation
- **Belal Emad** – قيادة جودة البيانات:  
  - توحيد تنسيقات التواريخ  
  - تنظيف الأسماء وإزالة التكرار  
  - معالجة القيم المفقودة في الحقول الحرجة  

- **Essam Abo Elmgd** – تنسيقات وتحويل أنواع البيانات.  

- **Bakr Ahmed** – اختبار إجراءات التنظيف والتحقق من العلاقات.  

- **Mostafa Mohamed** – التحقق من البيانات المنظفة ومطابقتها مع المصادر.

1. افتح مشروع Power BI المرفق.

4. استعرض لوحات التحكم النهائية بعد المعالجة.
